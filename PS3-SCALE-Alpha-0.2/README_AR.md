# PS3 SCALE — Alpha 0.2

**الهدف:** إدارة مكتبة ألعاب PS3 وPS2، عرض معلومات الألعاب، وتوفير ملفات تحسين خاصة بكل لعبة مع مطابقة دقيقة وحماية من التعديلات غير المتوافقة.

## حالة فرع التطوير

فرع feature/online-graphics-database يضيف قاعدة بيانات أونلاين تضم 40 ملفاً مجتمعياً كبداية، ومزامنة HTTPS، وربطاً مع webMAN MOD لتطبيق تعديل ذاكرة لمرة واحدة بعد تأكيد المستخدم. هذه الملفات مصنفة Community-Reported وليست مختبرة بشكل مستقل على جهاز المستخدم. نجحت اختبارات المضيف وبناء حزم PS3 في Run #240، وتم تنزيل الأثر والتحقق من ملفات ELF وSELF وPKG ورؤوس الحزم وبصمات SHA-256. الحزمة متاحة ضمن Artifacts، لكن هذا الفرع لم يُختبر بعد على الجهاز الفعلي، لذلك ما زال اختبار PS3 مطلوباً قبل اعتباره جاهزاً نهائياً. المراجعة Draft PR #6 ولم يتم دمجها بعد.

## الميزات

- فحص مجلدات ألعاب PS3 وPS2 على الهارد الداخلي وUSB والأقراص المركّبة.
- قراءة PARAM.SFO واستخراج Title ID أو PS2 serial عند توفره.
- فصل مكتبة PS3 عن PS2، والفرز الأبجدي، والبحث.
- شاشة Scan Games بقائمة مستقلة ومعلومات اللعبة والغلاف.
- لوحة بحث داخلية تعمل بيد PS3 وتدعم الإنجليزية والإسبانية والعربية والأرقام والحذف والتطبيق والإلغاء.
- اختيار اللغة عند أول تشغيل: English / العربية / Español، مع حفظ الاختيار في الإعدادات.
- شاشة Loading تعرض مراحل التهيئة والفحص المحلي، وتنفذ فحص المكتبة في خيط منفصل.
- خلفية Aurora Core ثلاثية الأبعاد منخفضة التعقيد، ويمكن إيقافها من Settings.
- Settings: Music ON/OFF، مستوى الصوت، Home Animation ON/OFF، اللغة، فحص تحديث USB، إعادة فحص المكتبة واستعادة الإعدادات.
- موسيقى الخلفية مضمّنة داخل PKG في USRDIR/theme.mp3؛ لا تحتاج إلى نسخها من USB بعد التثبيت.
- Companion Tools تعرض حالة اكتشاف Apollo Save Tool وArtemis PS3 وwebMAN MOD.
- فحص المكتبة Read-Only ولا يكتب أو يحذف أو يعيد تسمية ملفات الألعاب الأصلية.

## قاعدة بيانات تحسين الألعاب

- مزامنة ملف TSV صغير عبر HTTPS مع التحقق من شهادة الاتصال وحد أقصى لحجم التنزيل. يبدأ التحديث التلقائي عند فتح شاشة قاعدة بيانات التحسينات إذا تجاوز عمر النسخة المحلية 24 ساعة؛ تشغيل التطبيق والألعاب لا ينتظر الإنترنت.
- الاحتفاظ بآخر قاعدة بيانات صالحة إذا فشل الاتصال أو التحقق من البيانات الجديدة.
- مطابقة Title ID وAPP_VER معاً؛ اسم اللعبة وحده لا يكفي.
- عرض التأثير والمصدر ومستوى الثقة قبل أي تطبيق.
- تضم قاعدة البيانات 33 ملفاً أحادي الكتابة مؤهلاً للتجهيز لمرة واحدة، و6 ملفات متعددة الكتابات معطلة تلقائياً، وملفاً واحداً يدوياً فقط للعبة Brütal Legend لأنه يحتاج إعادة تطبيق داخل اللعبة. جميعها تقارير مجتمعية وليست اختبارات مستقلة على جهاز PS3 SCALE.
- ملفات التعديل متعددة الكتابات لا تُفعّل تلقائياً في هذا الإصدار.
- تفعيل ملف الكتابة الواحدة يتطلب إعادة التحقق من Title ID وAPP_VER للعبة HDD المثبتة، أو مطابقة اللعبة المركّبة من /dev_bdvd للألعاب القرصية، ثم تأكيد المستخدم ووجود webMAN MOD وPS3MAPI. تشغيل اللعبة لا يحتاج إلى وجود ملف تحسين؛ عند عدم وجود تطابق تبدأ دون تعديل. فحص webMAN/PS3MAPI وتجهيز ملف التحسين وتشغيل اللعبة تتم في خيوط منفصلة حتى لا تتجمد واجهة التحكم عند تأخر الخدمة.

## تطبيق الذاكرة عبر webMAN

بعد تأكيد المستخدم، ينشئ PS3 SCALE سكربت webMAN لمرة واحدة خاصاً بـ Title ID. قبل Start Game يقارن التطبيق محتوى السكربت بالكامل بالنسخة التي أنشأها؛ وجود العنوان V2 وحده لا يكفي، وأي تعديل يدوي يجعل الملف قديماً ويمنع التشغيل حتى إزالته أو إعادة إنشائه. عند تشغيل اللعبة، يتحقق السكربت من Title ID وحالة اللعبة، ثم يبحث في عنوان ذاكرة واحد فقط ويتطلب تطابق البايتات الأصلية قبل الكتابة. بعد محاولة التشغيل يحذف السكربت نفسه لتقليل خطر إعادة استخدام تعديل قديم.

التعديل يخص ذاكرة عملية اللعبة فقط؛ لا يغيّر ملفات ISO أو EBOOT أو مجلد اللعبة. إغلاق اللعبة ينهي العملية ويزيل التعديل من الذاكرة. لا تظهر رسالة نجاح أو صفارة بعد المحاولة لأن مسار webMAN الحالي لا يوفّر للتطبيق تحققاً موثوقاً من قيمة الذاكرة بعد الكتابة.

**ملاحظة مهمة:** webMAN لا يوفّر شرط APP_VER مباشراً داخل السكربت. لذلك يتحقق PS3 SCALE من الإصدار قبل تجهيز السكربت، ثم يتحقق من إصدار اللعبة المركّبة عند الضغط على Start Game. لا تحدّث اللعبة بين تجهيز الملف وتشغيلها، واستخدم Start Game من PS3 SCALE.

## اكتشاف الجهاز

- يقرأ التطبيق إصدار النظام وPlatform ID من استعلامات للقراءة فقط، ويعرض عائلة الجهاز وسلسلة الموديل.
- يحاول قراءة نوع CEX / DEX / DEH بشكل منفصل؛ إذا منعت بيئة CFW الاستعلام يظهر UNKNOWN ويستمر التطبيق.
- لا يقرأ التطبيق IDPS أو PSID.
- راجع docs/HARDWARE_DETECTION.md لمعرفة حدود تحديد موديل CECH الدقيق.

## اللغات العربية والإسبانية

- الواجهة العربية تستخدم مجموعة محارف bitmap مضمّنة مع تشكيل أساسي واتجاه RTL.
- اختبارات المضيف تتحقق من الجمل العربية والمختلطة والأرقام، لكنها لا تغني عن اختبار القراءة الفعلية على شاشة PS3.
- التشكيل مخصص لنصوص الواجهة وليس محرك Unicode كاملاً؛ قد لا تظهر بعض المحارف أو الحركات أو أسماء الألعاب متعددة الاتجاهات بشكل مثالي.
- ترخيص Noto Sans Arabic موثق في docs/THIRD_PARTY_LICENSES.txt.

## التحكم

- القائمة الرئيسية: UP/DOWN ثم CROSS للفتح، CIRCLE للخروج.
- Scan Games: UP/DOWN للتنقل، L1/R1 للتبديل بين PS3/PS2، SELECT/START للبحث، SQUARE لإعادة الفحص، CROSS للتفاصيل، CIRCLE للرجوع.
- لوحة البحث: الأسهم للتنقل، CROSS لإضافة المفتاح أو تنفيذ الأمر، CIRCLE للإلغاء.
- PS2 ISO: TRIANGLE لمعاينة CONFIG فقط.
- تفاصيل لعبة PS3: CROSS/START لتشغيل اللعبة المحددة؛ ألعاب HDD تُشغّل عبر Title ID، وملفات ISO/المجلدات عبر مسارها في webMAN. إذا لم يوجد ملف تحسين مطابق، تعمل اللعبة بشكل طبيعي دون تعديل. التشغيل في خيط منفصل حتى تبقى أزرار التحكم مستجيبة. SQUARE لتجهيز/إزالة ملف التحسين، TRIANGLE للتأكيد، CIRCLE للرجوع.
- Online Graphics Database: UP/DOWN للتحديد، CROSS لفتح اللعبة المطابقة، SQUARE لحفظ بيانات الملف، TRIANGLE لحفظ الملفات المطابقة، START للمزامنة.
- Settings: UP/DOWN للتنقل، CROSS للتبديل/التنفيذ، LEFT/RIGHT للصوت أو تغيير اللغة.

## حدود الإصدار

- لا يوجد Universal AI Upscaler أو Frame Generation.
- لا نضمن 60 FPS ثابتاً؛ النتيجة تعتمد على اللعبة والملف والجهاز.
- قاعدة البيانات المجتمعية لا تعني أن كل تعديل تم اختباره على كل موديلات PS3.
- لا يوجد تحقق بعد الكتابة من قيمة الذاكرة، لذلك لا يعرض التطبيق رسالة نجاح مزيفة.
- ملفات PS2 CONFIG ما زالت في مسار المعاينة المنفصل ولا تستخدم ملفات تعريف PS3.

## تثبيت نسخة CFW

1. نزّل Artifact باسم `PS3-SCALE-Alpha-0.2-build-with-embedded-theme` من Run #240.
2. فك ضغط ZIP على الكمبيوتر.
3. انسخ `ps3scale.gnpdrm.pkg` إلى جذر USB مهيأ FAT32.
4. على PS3 CFW افتح **Package Manager → Install Package Files → Standard** واختر الملف.
5. افتح **PS3 SCALE** من Game ثم جرّب أولاً التشغيل والفحص والإعدادات والموسيقى فقط.
6. لا تختبر ملف تحسين قبل تأكيد موديل الجهاز وإصدار اللعبة، وابدأ بملف واحد فقط بعد مراجعة مصدره.

لا تستخدم `ps3scale.pkg` (نسخة debug) للتثبيت العادي. ملف التثبيت المقصود لـ CFW هو `ps3scale.gnpdrm.pkg`.

## جهاز الاختبار المستهدف

الجهاز المستهدف حسب المعلومات المتوفرة: PS3 Slim مع CFW 4.92. رقم CECH الدقيق ونوع CEX/DEX وإصدار Cobra لم يتم التحقق منها بعد. يجب اختبار واجهة العربية والإنجليزية والصوت وحركة 3D ومزامنة قاعدة البيانات وملف تحسين واحد على الجهاز الفعلي قبل إعلان دعم نهائي.

## البناء والاختبار

في بيئة PS3DEV / PSL1GHT / Tiny3D:

~~~sh
export PS3DEV=/usr/local/ps3dev
export PSL1GHT=$PS3DEV
export PATH=$PATH:$PS3DEV/bin:$PS3DEV/ppu/bin:$PS3DEV/spu/bin
make clean
make pkg
~~~

اختبارات الكمبيوتر:

~~~sh
chmod +x scripts/test_host.sh
./scripts/test_host.sh
~~~
