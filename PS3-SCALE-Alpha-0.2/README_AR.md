# PS3 SCALE — Alpha 0.33

**الهدف:** إدارة مكتبة ألعاب PS3 وPS2، عرض معلومات كل لعبة، ومراجعة ملفات تحسين FPS المتاحة مع مطابقة دقيقة قبل تثبيتها.

## حالة المشروع

هذا هو فرع التطوير المرتبط بـ Draft PR #16. اجتاز Alpha 0.33 اختبارات Host وDeno وبناء ELF/SELF/PKG في GitHub Actions رقم 865. لا تدمج الفرع قبل مراجعة التغييرات واختبار الحزمة على جهاز PS3 فعلي؛ نجاح البناء لا يغني عن تجربة الميزات على الجهاز.

## الواجهة

- الهوية البصرية تعتمد سلّماً حلزونياً واحداً بألوان اللؤلؤي واللافندر.
- كل من صورة التطبيق الأساسية `ICON0.PNG` وصورة المعاينة الكبيرة `PIC0.PNG` تستخدمان شعار PS3 SCALE Neon Glass نفسه؛ وخلفية XMB `PIC1.PNG` تستخدم مشهد السلم الحلزوني الواحد.
- أزيل عنوان FEATURES من الصفحة الرئيسية، وأزيلت صورة الأيقونة الإضافية من شاشة About.
- شاشة Game Details لا تعرض رسماً تخيلياً على أنه صورة لعبة؛ تبحث عن صورتين حقيقيتين مرتبطتين بـ Title ID وAPP_VER، وتعرض حالة واضحة إذا لم تتوفر الصور.
- أسماء عناصر قائمة الموسيقى أصبحت Music 1 وMusic 2، مع بقاء وصف مصدر كل مسار في رسائل الحالة.

## المكتبة والفحص

- فحص ألعاب PS3 وPS2 من الهارد الداخلي وUSB والأقراص المركّبة، مع دعم ملفات PS2 ISO بامتدادات `.ISO` و`.BIN` و`.IMG` و`.MDF`، وفصل ملفات `.BIN.ENC` ضمن PS2 Classics.
- قراءة PARAM.SFO لاستخراج Title ID وAPP_VER أو PS2 serial عند توفره.
- فصل مكتبة PS3 عن PS2، مع الفرز والبحث وعرض تفاصيل اللعبة.
- فحص المكتبة Read-Only؛ لا يعيد تسمية ملفات الألعاب ولا يحذفها ولا يغيّر EBOOT أو ISO.
- الواجهة والبحث يعملان من يد تحكم PS3، وتتم أعمال الشبكة والفحص الطويل في خيوط منفصلة حتى لا تتجمد الواجهة.

## Online DB

- أول فتح لشاشة Online DB يبدأ تحديث HTTPS تلقائياً، مع إبقاء آخر نسخة محلية صالحة ظاهرة أثناء التحديث.
- Triangle ينفذ تحديثاً فعلياً لقاعدة البيانات. Start يبقى اختصاراً إضافياً للتحديث.
- Select يفتح البحث، وSquare يبدّل المرشحات.
- المرشح الافتراضي ALL FILES + ANY REGION/VERSION؛ تظهر ملفات الفهرس فور فتح الشاشة، بما فيها النتائج التي لا تطابق لعبة محلية بعد، وتبقى هذه النتائج للعرض فقط حتى يتم فحص اللعبة المطابقة.
- النتائج غير المطابقة للإصدار تظهر للمراجعة فقط ولا يمكن تثبيتها.
- يمكن تصفح آخر Cache صالح عند انقطاع الإنترنت؛ لا يلزم حساب PSN لمزامنة قاعدة البيانات.

## تثبيت ملفات NCL في Artemis

زر Cross يثبت ملف NCL فقط عندما تتحقق الشروط التالية:

1. التصنيف في قاعدة البيانات هو GRAPHICS_FPS.
2. امتداد الملف `.ncl`.
3. اللعبة ممسوحة وموجودة على الهارد الداخلي تحت `/dev_hdd0/`.
4. Title ID وAPP_VER للعبة المثبتة يطابقان بيانات الملف تماماً.
5. Artemis PS3 مثبت؛ يتعرف التطبيق تلقائياً على مسار الحزمة الرسمية `ARTPS3001` أو حزمة Artemis R5 ذات المعرّف `ARTZ00001`.
6. مسار GitHub آمن، وحجم الملف لا يتجاوز 2 MiB، ومحتواه نصي وليس ELF أو PKG أو بيانات ثنائية.

يُحفظ الملف داخل مجلد USERLIST الخاص بنسخة Artemis المكتشفة. ويُضاف إلى اسمه Title ID وإصدار اللعبة لتسهيل التعرف عليه.

**مهم:** PS3 SCALE لا ينفّذ ملف NCL ولا يطبقه تلقائياً. بعد تنزيله افتح Artemis PS3 واختر الملف المطابق للعبة. لا يتم تعديل ملفات اللعبة الأصلية أو EBOOT أو ISO.

### وضع التخزين

من Settings → Enhancement Storage:

- **TEMPORARY** هو الوضع الافتراضي. يسجل التطبيق ملفات NCL المؤقتة ويحذفها عند تشغيل PS3 SCALE في المرة التالية.
- **PERMANENT** يحتفظ بالملفات الجديدة في USERLIST إلى أن تحذفها يدوياً.

لا يغيّر تبديل الإعداد الملفات التي سبق تنزيلها؛ ينطبق على التنزيلات الجديدة فقط.

## ملفات المقارنة Before / After

يقرأ التطبيق صور PNG من:

`/dev_hdd0/game/PS3SCALE1/USRDIR/previews/`

ويحتاج صورتين لكل لعبة وإصدار:

- `<TITLE_ID>_<APP_VER>_before.png`
- `<TITLE_ID>_<APP_VER>_after.png`

يجب أن تكون الصورتان من اللعبة نفسها وبنفس المشهد والإصدار، قبل التعديل وبعده. المقاس المقترح 640×360. إذا غابت إحدى الصورتين، لا يعرض التطبيق رسماً بديلاً أو صورة تسويقية.

لا توجد حالياً أزواج صور Before/After حقيقية مرفقة لكل الألعاب داخل المستودع. محرك التحميل واتفاقية أسماء الملفات جاهزان، لكن يلزم توفير لقطات أصلية موثوقة لكل Title ID وAPP_VER حتى تظهر المقارنة.

التفاصيل في `docs/GAME_PREVIEWS.md`.

## ملفات FPS وwebMAN MOD

- ملفات FPS في Online Profiles تتطلب تطابق Title ID وAPP_VER قبل تجهيز تعديل الذاكرة.
- الضغط على CROSS أو START من Game Details هو تأكيد صريح. يتحقق التطبيق من Title ID وAPP_VER داخل Background Worker وليس داخل حلقة التحكم. قوائم الفحص الكبيرة محفوظة في Static Memory لتجنب تجاوز Stack، وتبقى الواجهة مستجيبة أثناء فحص الهارد أو القرص. إذا تغيّرت هوية اللعبة أو إصدارها، لا يطبّق التطبيق الملف المحسّن. وإذا تعذّر تجهيز الملف لأسباب آمنة مثل غياب PS3MAPI أو فشل التحقق، يحاول تشغيل اللعبة الأصلية دون تعديل بشرط أن يبقى اختيار اللعبة نفسه. أما إذا كان webMAN لا يستجيب أو وُجد سكربت مستخدم لا يملكه التطبيق، فيوقف العملية دون الكتابة فوقه.
- ملفات الكتابة المتعددة والملفات اليدوية لا تُفعّل تلقائياً.
- سكربت webMAN يتحقق من Title ID وحالة اللعبة والبايتات الأصلية قبل محاولة الكتابة، ثم يحذف نفسه بعد المحاولة.
- إذا لم يكن PS3MAPI متاحاً، يزيل التطبيق سكربت PS3 SCALE الخاص بالتعديل ويحاول تشغيل اللعبة دون ملف التحسين؛ غياب PS3MAPI لا يمنع تشغيل اللعبة العادي.
- تهيئة NET وNETCTL تتم قبل الاتصال بخدمة webMAN المحلية على `127.0.0.1:80`. عند فشل الاتصال أو رفض HTTP يعرض التطبيق سبباً محدداً بدلاً من رسالة عامة.
- لا يتم تعديل ملفات ISO أو EBOOT أو مجلد اللعبة في مسار تعديل الذاكرة.

## تشغيل الأدوات المرافقة

من الصفحة الرئيسية اضغط SELECT لفتح Companion Tools:

- UP/DOWN للتبديل بين Apollo Save Tool وArtemis PS3.
- CROSS يطلب من webMAN MOD فتح الأداة المحددة مباشرةً، دون الحاجة للرجوع إلى XMB والتنقل يدوياً. فحص ملف webMAN مجرد مؤشر؛ إذا كان مثبتاً بمسار مختلف، سيحاول التطبيق الاتصال بالخدمة المحلية بدلاً من منع التشغيل.
- يتعرف التطبيق على Apollo بالمعرّف NP0APOLLO، وعلى Artemis الرسمي ARTPS3001 أو Artemis R5 بالمعرّف ARTZ00001.
- TRIANGLE يعيد فحص حالة البرامج، وCIRCLE يرجع للقائمة الرئيسية.
- يجب أن يكون webMAN MOD مثبتاً ومفعلاً حتى يعمل مسار الفتح. نجاح طلب HTTP يعني أن webMAN قبِل الطلب، وليس إثباتاً مستقلاً أن واجهة البرنامج ظهرت فعلياً.

عمليات إدارة الحفظ والاسترجاع وإعادة التوقيع تبقى داخل Apollo Save Tool نفسه، وتشغيل أكواد NCL يبقى داخل Artemis. هذه النسخة تضيف فتحاً مباشراً للأداتين ولا تدّعي أنها نقلت محركاتهما إلى PS3 SCALE.

## إدارة PS2 CONFIG

من Game Details اضغط SQUARE لفتح PS2 CONFIG Manager:
- BACK UP CURRENT CONFIG: ينشئ نسخة احتياطية مستقلة ويتحقق من تطابقها بايتاً ببايت؛ لا يستبدل نسخة احتياطية موجودة.
- RESTORE SAVED BACKUP: يستعيد النسخة الاحتياطية بطريقة ذرية، ويحفظ الملف الحالي كنسخة Rollback إذا كان موجوداً.
- DOWNLOAD / REPLACE CONFIG: لا ينزّل إلا ملفاً مطابقاً لقاعدة البيانات. استبدال ملف موجود يتطلب Backup يطابق الملف الحالي تماماً؛ وإلا يتم رفض العملية.
- يدعم ملفات PS2 ISO `.CONFIG` وملفات PS2 Classics `.ENC`. الحد الأقصى 16 KiB لملفات CONFIG و32 KiB لملفات ENC.
- لا يكتب التطبيق داخل ISO أو EBOOT أو ملفات اللعبة الأصلية. كل تعديل يتطلب ضغط CROSS صراحةً داخل مدير PS2.
- في اختبارات المضيف تُرفض مسارات Symbolic Links. على PS3 تُنشأ الملفات المؤقتة حصرياً (O_EXCL)، وتُستبدل الملفات بـ Rename ذري؛ لذلك لا تُفتح وجهة مؤقتة موجودة للكتابة ولا يُحذف CONFIG الحالي قبل نجاح الاستبدال.

اختبارات الكمبيوتر تغطي النسخ الاحتياطي والاستعادة والـ Rollback ومنع الاستبدال غير الآمن. يلزم اختبار فعلي على PS3 قبل إعلان اكتمال التوافق على الجهاز.

## نظام بلاغات الدعم — Alpha 0.33

- كل بلاغ يُحفظ كملف JSON مستقل باستخدام الحفظ الذري قبل محاولة الإرسال.
- لكل بلاغ UUID ثابت لمنع تكرار السجل عند إعادة الإرسال.
- البلاغات المعلقة تبقى بعد إغلاق التطبيق ويمكن إعادة إرسالها من Help & Support عبر Retry Pending.
- لا يُحذف ملف البلاغ إلا بعد استلام استجابة نجاح من الخادم.
- كود Supabase جاهز، لكن الإرسال الفعلي يبقى معطلاً حتى إنشاء المشروع المنفصل وإعداد رابط الخدمة والمفتاح العام.

## موثوقية الحفظ والتنزيل — Alpha 0.33

- حفظ الإعدادات والمفضلة يتم بملف مؤقت حصري داخل المجلد نفسه ثم استبدال ذري باستخدام Rename؛ إذا فشل الحفظ تبقى النسخة السابقة كما هي.
- ملفات تنزيل HTTPS المؤقتة تستخدم أسماء فريدة وفتحاً حصرياً O_EXCL، لذلك لا تُكتب فوق ملفات مؤقتة قديمة ولا تُحذف لمجرد فشل الاتصال.
- إذا فشل تنزيل ملف NCL أو PS2 CONFIG أو قاعدة البيانات قبل اكتماله، لا يحذف التطبيق ملف وجهة كان موجوداً قبل بدء العملية.
- سكربت webMAN المؤقت لا يكتب فوق ملف موجود أو Symbolic Link؛ وإذا كان المسار المؤقت مشغولاً تتوقف العملية بأمان.
- اختبارات Host CI تشمل الكتابة الذرية، الروابط الرمزية، الملفات المؤقتة الموجودة مسبقاً، وسيناريوهات فشل التنزيل.

## تقارير الدعم

تُحفظ تقارير المشاكل والملاحظات أولاً في Local Outbox على الهارد الداخلي. الإرسال عبر الإنترنت متوقف حالياً لأن خدمة PS3 SCALE تحتاج مشروع Supabase منفصلاً ومخصصاً لها مع إعداد الأسرار على الخادم. لا تُرسل التقارير إلى أي مشروع آخر، ولا يحتوي التطبيق على مفاتيح خدمة أو بيانات PSN.


## التحكم

- القائمة الرئيسية: UP/DOWN ثم CROSS للفتح، CIRCLE للرجوع أو الخروج.
- Scan Games: UP/DOWN للتنقل، L1/R1 للتبديل بين PS3/PS2، SELECT/START للبحث، SQUARE لإعادة الفحص، CROSS للتفاصيل.
- تفاصيل اللعبة: CROSS أو START لتطبيق ملف الذاكرة المطابق والمؤهل ثم تشغيل اللعبة؛ إذا لم يوجد ملف مطابق تبدأ اللعبة الأصلية دون تعديل. SQUARE يفتح FPS Control لألعاب PS3، ويفتح PS2 CONFIG Manager لألعاب PS2 لإجراء Backup / Restore أو تنزيل CONFIG مطابق. استبدال ملف موجود يتطلب نسخة احتياطية مطابقة بايتاً ببايت، ويحفظ النسخة السابقة كملف Rollback.
- FPS Control: UP/DOWN للاختيار، CROSS لتجهيز ملف، TRIANGLE لتأكيد التطبيق، SQUARE لإزالة ملف PS3 SCALE المعلّق، CIRCLE للرجوع.
- Online DB: UP/DOWN للتحديد، LEFT/RIGHT للتنقل بين الصفحات، L1/R1 للنتيجة السابقة/التالية، CROSS لتثبيت NCL المطابق أو فتح تفاصيل ملف Profile، TRIANGLE للتحديث، SELECT للبحث، SQUARE لتبديل المرشح، CIRCLE للرجوع.
- Settings: UP/DOWN للتنقل، CROSS للتبديل أو التنفيذ، LEFT/RIGHT لتغيير القيمة.
- Companion Tools: SELECT من Home، UP/DOWN لاختيار Apollo أو Artemis، CROSS للفتح، TRIANGLE لتحديث الحالة، CIRCLE للرجوع.

## الحدود المعروفة

- لا يوجد Universal AI Upscaler أو Frame Generation.
- لا يوجد Slider عام يغير FPS لأي لعبة؛ كل تعديل مرتبط بملف خاص بعنوان اللعبة وإصدارها.
- فتح حد FPS لا يضمن 60 إطاراً ثابتاً، وقد تتأثر الفيزياء أو سرعة اللعبة.
- ملفات NCL وبيانات المجتمع ليست مختبرة بشكل مستقل على كل موديلات PS3؛ راجع المصدر قبل استخدامها.
- التطبيق لا يضمن أصالة الصور بمجرد مطابقة اسمها؛ يجب توفير لقطات حقيقية من المصدر نفسه.
- ملفات PS2 CONFIG تبقى في مسار توافق منفصل، وليست تحسينات رسومية أو ملفات FPS.

## البناء والاختبار

في بيئة PS3DEV / PSL1GHT / Tiny3D:

~~~sh
export PS3DEV=/usr/local/ps3dev
export PSL1GHT=$PS3DEV
export PATH=$PATH:$PS3DEV/bin:$PS3DEV/ppu/bin:$PS3DEV/spu/bin
make clean
make pkg
~~~

اختبارات الكمبيوتر:

~~~sh
chmod +x scripts/test_host.sh
./scripts/test_host.sh
~~~

من GitHub Actions نزّل أحدث Artifact ناجح لفرع التطوير. حزمة GNPDRM هي نسخة التثبيت العادية على CFW؛ لا تعتمد على نجاح CI وحده لإعلان توافق الجهاز، بل اختبر التثبيت والفحص والمزامنة وتشغيل لعبة واحدة على PS3 فعلي.

**Community NCL integrity:** verified downloads require an exact Title ID / game version match, the indexed file size, and the GitHub Git-blob SHA-1. Legacy index entries without a blob hash are discovery-only until the community index is refreshed. This hash check is not a cryptographic signature.
