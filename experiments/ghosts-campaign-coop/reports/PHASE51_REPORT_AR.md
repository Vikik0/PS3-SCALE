# تقرير المرحلة 51 — مصدر منطقة TOC وحالة تهيئتها

## المشكلة

قد يكون عنوان TOC موجوداً داخل ذاكرة Ghidra دون أن يكون جزءاً من منطقة بيانات عادية محمّلة وقت التشغيل. يمكن أن تحتوي قاعدة Ghidra على مناطق غير مهيأة أو صناعية أو خارجية، ولا يجوز اعتبارها تلقائياً بيانات صالحة للعبة.

## التعديلات

1. أصبح كل TOC مربوط يسجل خصائص MemoryBlock التالية: Loaded وInitialized وArtificial وExternal وVolatile.
2. تصدر الخصائص كقيم JSON منطقية.
3. إذا كان TOC صفرياً أو غير مربوط، يجب أن تكون خصائص المنطقة null بدلاً من اختلاق خصائص لمنطقة غير موجودة.
4. أصبح محلل Python يرفض بيانات المنطقة المربوطة إذا كانت خصائص المصدر ناقصة أو غير منطقية.
5. أضيفت إحصائيات تفصل المناطق المحمّلة والمهيأة عن المناطق الصناعية والخارجية.

## حدود المرحلة

الاختبارات تستخدم بيانات صناعية وتحققاً من وجود خصائص API في سكربت Ghidra. هذه الخصائص تصف نموذج الذاكرة المستورد إلى Ghidra، ولا تثبت وجود المنطقة نفسها أثناء تشغيل اللعبة أو صحة TOC أو أمان استدعاء الدالة داخل Campaign.
