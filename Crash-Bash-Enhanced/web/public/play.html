BROWSER PLAYER

Run your own Crash Bash disc image locally in the browser. The experimental CBN1 client can join a PS3-hosted room. For the first test, use the same NTSC-U disc revision on both systems; PAL timing is not verified. Start with Battle/minigame modes: Adventure memory-card save synchronization is not implemented.

Your disc image and BIOS are read in this browser only. They are not uploaded to the matchmaking Worker or stored on the project server. Use a game image and BIOS dump you are legally entitled to use. Desktop Chrome or Edge is recommended for large disc images.
LOCAL MODE · Load the game, then connect from a PS3-hosted room. Cross-platform synchronization is experimental and not yet hardware-verified. The PS3 host must create the room first.
For a multi-track BIN/CUE dump, select the CUE and every file it references. Single-file CHD/PBP/ISO is simpler.
Some game/core combinations require a BIOS dump from your own console.
Select your disc image to continue.
